# Runtime dependencies, Phase 1.
#
# Direct dependencies are pinned exactly so a local run, a CI run, and a Docker
# build resolve to the same versions. Transitive dependencies are intentionally
# not pinned here: development happens on Windows and macOS while CI and the
# image are Linux, and a full cross-platform lockfile pinned from one OS breaks
# on the others (uvicorn's uvloop extra is the concrete example, it has no
# Windows build). Revisit with a proper multi-platform lock tool if drift in a
# transitive dependency ever actually causes a failure.

uvicorn[standard]==0.52.4
pydantic==2.13.5
